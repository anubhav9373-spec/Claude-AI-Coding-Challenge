# Day 39 - PDF Splitter & Merger

## Overview

A professional browser-based PDF utility that allows users to split and merge PDF documents directly in their browser. All processing happens locally on the device, ensuring privacy, security, and offline usability.

## Features

- Split PDFs using custom page ranges
- Split after specific pages
- Split every N pages
- Extract selected pages into a new PDF
- Merge multiple PDF files
- Drag-and-drop file uploads
- Drag-and-drop file reordering
- PDF thumbnail previews
- ZIP download for multiple split outputs
- Dark and Light theme support
- Keyboard shortcuts
- Responsive SaaS-style interface
- Client-side PDF processing

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- PDF-lib
- PDF.js
- JSZip

## Learning Outcomes

- Working with PDF manipulation libraries
- Client-side document processing
- File handling in browsers
- Drag-and-drop UX implementation
- Building productivity-focused web applications
- Creating responsive SaaS-style interfaces

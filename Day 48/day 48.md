# Day 48 - The Verdict Engine

## Overview

The Verdict Engine is an interactive decision-support web application developed as part of the **60 Days Claude AI Challenge**.

The application helps users compare leading AI coding assistants using weighted evaluation criteria and research-backed comparisons. Users can adjust priorities in real time and instantly see how rankings change based on their personal preferences.

---

## Features

- Compare ChatGPT, Claude, Gemini, and GitHub Copilot
- Live weighted scoring algorithm
- Dynamic ranking updates
- Adjustable priority sliders
- Multiple preset comparison profiles
- Professional comparison dashboard
- Research transparency section
- Sources and citations panel
- Responsive modern UI
- Pure HTML, CSS, and Vanilla JavaScript
- Offline-compatible single HTML file

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design
- Dynamic DOM Manipulation
- Weighted Scoring Algorithm

# Day 27 - Prior Authorization Story Simulator

## Overview

Prior Authorization Story Simulator is an interactive healthcare education application that teaches users how the Prior Authorization (PA) process works through a story-driven experience.

Users follow Rahul's healthcare journey after being diagnosed with Rheumatoid Arthritis and prescribed Humira.

Through conversations with Priya, a healthcare operations specialist, users learn how insurance reviews, denials, appeals, and approvals work in real-world healthcare systems.

## Features

- Interactive 8-scene healthcare story
- Patient and healthcare specialist conversations
- Multiple decision paths
- Educational healthcare insights after every scene
- Progress tracking system
- Timeline and day counter
- Knowledge scoring system
- Multiple outcome paths
- Completion dashboard
- Premium healthcare-themed UI
- Responsive design
- Restart story functionality
- Debug panel for story tracking

## Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript

## Learning Outcomes

- Understanding Prior Authorization workflows
- Insurance review processes
- Medical necessity documentation
- Step therapy requirements
- PA denials and appeals
- Healthcare operational metrics
- Patient and payer perspectives
- Healthcare workflow efficiency

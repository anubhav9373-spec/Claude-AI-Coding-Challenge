# Day 50 - DEFEND// TERMINAL

## Overview

DEFEND// TERMINAL is an AI-powered interview preparation platform designed to help users confidently defend every claim made in their resume, portfolio, or professional experience.

Instead of improving a resume, the application acts as a skeptical engineering manager that cross-examines each claim with adaptive follow-up questions. The goal is to expose weak explanations, encourage evidence-based responses, and prepare users for real-world technical interviews.

Built as part of the **60 Days Claude AI Challenge – Day 50**.

---

## Features

### Resume Processing
- Upload PDF, DOCX, DOC, TXT, and Markdown files
- Drag-and-drop file support
- Manual text input
- Automatic resume text extraction

### AI Claim Extraction
- Detects meaningful claims from resumes
- Prioritizes high-risk and high-impact statements
- Creates an interactive Claims Ledger
- Identifies areas that require stronger evidence

### Adaptive Interview Simulator
- Engineering Manager interview persona
- Personalized follow-up questions
- Difficulty modes:
  - Friendly
  - Realistic Pressure
  - Brutal Skeptic
- Conversation adapts based on user responses

### Defense Analytics
- Live defense score
- Confidence tracking
- Claim status indicators
- Activity log
- Progress tracking

### Defense Report
- Strong claims summary
- Weak claim identification
- Improvement recommendations
- Downloadable report

### Session Management
- Local Storage persistence
- Resume previous sessions
- Export interview logs
- Download defense reports
